# 科研图提示词

从本次幻灯片大纲挑选确实需要图示的页面。默认约五张。明确指定数量时统计复用和生成的成品图，0 表示不输出图文件。可优先考虑研究背景与应用场景、研究问题与现有方法不足、整体研究方法架构、核心模型或数据结构、算法执行流程、实验设计与评测流程。选图依据是该页有可视化能解释的关系。图稿随研究方向变化。

先在工作目录创建 prompts/公共科研图片风格.md，再为每张图准备独立提示词，图中文字默认使用报告的主要语言。共用规范记录适合本研究领域的参考风格、配色、线条、节点、字体用法、图内留白和精确性要求。可参考 ACL、EMNLP、ICLR、NeurIPS、ICML、CVPR 等领域会议的科研图，也可采用与当前研究相关的其他学科规范。

默认采用纯白背景、扁平矢量科研绘图风格、低饱和度配色、清晰模块边界、统一节点形状、细线有向箭头、明确信息流与层次、充分留白、易读的文字和准确的数学符号。专业缩写和数学标记可保留英文。禁止三维效果、渐变、投影、无关装饰、虚构实验数据及性能指标。每张图沿用同一规范，可按版面调整布局和比例。

成品图与逐图 Markdown 一起放在项目的 figures/。同一个基名包含两位页码和所属章节的短标题，如 figures/Frame 06-整体研究方法架构.png 与 figures/Frame 06-整体研究方法架构.md。用实际章节命名，重复章节可补充短主题。替换文件名中不适合跨平台的符号。TikZ 图使用同一基名导出为 PDF 矢量图或 PNG，再按相对路径引入。独立绘图源留在工作目录。

## 每张图的独立提示词

遵循 [SKILL.md](../SKILL.md) 中的「插图 Prompt 信息密度红线」。参考[跨会话长期记忆的提示词和成图](figure-prompt-example.md)如何用三个具体会话、记忆状态变化与错误检索的局部标记讲清关系。新图的细节从本次报告提取。先明确图的表达目标，再把支撑理解的例子、状态、条件和局部标注分别写入下列对应项，并在最终 Prompt 和成图中逐项核对。

1. 图片主题
2. 对应 Frame 与所属章节
3. 科研表达目标
4. 整体布局
5. 核心研究对象及支撑理解的具体例子
6. 模块关系、关键条件、分支，以及箭头的起点、终点和方向
7. 数据流或算法步骤，以及需要呈现的状态变化
8. 必须准确保留的公式和专业符号
9. 图内原样文字、局部标注、图例及语言要求
10. 配色与视觉规范，写明本图相关的共用规范
11. 图片宽高比，按整页、跨栏或单栏面积选择
12. 图片输出文件名
13. 禁止生成的内容，包含本图易产生的事实、关系或数值错误

必需的公式和长标签可在 Beamer 中贴近对应图形排版，作为图的一部分。用「无」明确不适用的项，例如没有公式的背景图。实际提交给生图工具的提示词带上相关共用规范及该图独立要求。图稿可根据报告事实写入并标注示意场景。未知关系标为未知。现有图也用同名提示词文件记录插图规格和来源，并标为复用。

## 与成品图一同交付

每份 Markdown 保存上面的 13 项。另列「生成方式」和「模型」；API 回包未报告模型时，分别注明请求的模型 ID 和未独立确认的实际模型。对 Codex 内置工具，只有工具选择项或返回值确认时才标记 Images 2.6，否则标记具体模型未确认。把生成所选成品图的完整实际提交文本放在「实际提交的提示词」下，包含当时发送的共用规范和最终修改要求。使用 TikZ 时注明「TikZ 绘制」，记录设计说明；复用已有图时注明来源和已知生成信息。文件只保留已去标识的内容，不写 API 密钥、带凭据的 URL 或原附件全文。
